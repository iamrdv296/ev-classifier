
# Contributing

Thanks for your interest in contributing!

## Getting started

1. Fork this repository.
2. Clone your fork.
3. Create a branch for your changes.
4. Make your changes.
5. Run the checks:
   - `cargo test`
   - `cargo fmt --check`
   - `cargo clippy`
6. Submit a Pull Request.

## Guidelines

- Keep changes focused.
- Follow the existing Rust code style.
- Add tests when appropriate.
- Explain what your changes do in the Pull Request.

## Issues

Before opening an issue, check whether it already exists.

For significant changes, discuss your proposal in an issue first.
